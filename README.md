# TACT — Tactical Arena Control Tool

TACT is a handheld game controller for airsoft and other field games. It runs the game for you: it keeps
the clock, handles the objective (a bomb, a control point, a passcode, respawn tickets), decides the
winner and keeps the stats. Several TACT devices can link over Wi-Fi and play one game together.

![TACT main menu](https://raw.githubusercontent.com/wiki/luminko/tact/images/main-menu.png)

> **Status: pre-release (0.9.x).** Firmware is not published yet.
